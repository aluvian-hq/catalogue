# Aluvian catalogue

The catalogue source Aluvian AG publishes for Gentian OS clusters: an
`index.yaml` naming every entry with its version and digest, and one
component profile per entry under `profiles/`. It is served as static files at
<https://catalogue.aluvian.io>.

Everything here except this file is generated and replaced on each
publication. Changes made by hand are overwritten; nothing is developed in
this repository.
